# 🖱️ Mouse Tracker

**Mouse Tracker** is a Windows desktop application that tracks your mouse activity, displays statistics, and turns everyday computer use into a more interactive experience.

Monitor your mouse clicks, track the distance your cursor travels, unlock achievements, and compare your results with other users.

## ✨ Features

- **Mouse Tracking** — Track mouse clicks and cursor movement distance.
- **Live Overlay** — View your activity in a compact, transparent tracker.
- **Detailed Statistics** — Explore your mouse activity and progress.
- **Achievements** — Unlock achievements as you use your computer.
- **Customizable Skins** — Personalize the appearance of your tracker.
- **Global Leaderboard** — Compare your statistics with other players.
- **User Accounts** — Keep your statistics associated with your account.
- **Multiple Languages** — English and Ukrainian interface.
- **Automatic Updates** — Receive new versions directly through the application.

## 📥 Download & Installation

**[⬇️ Download the Latest Version](https://github.com/Online129/MouseTracker-Releases/releases/latest)**

1. Open the download link above.
2. Under **Assets**, download `MouseTracker-Setup-vX.X.X.exe`.
3. Run the installer and follow the instructions.
4. Launch Mouse Tracker and start tracking!

You do not need to install .NET separately with current releases.

## 💻 System Requirements

- Windows 10 or Windows 11 (64-bit)
- Internet connection for online features

## 🔄 Automatic Updates

Mouse Tracker automatically checks for new versions through GitHub Releases.

When an update is available, you can download and install it directly from the application.
